Gentoo Linux 极致安装指南：从 Stage3 到 Plasma 桌面

2026.01.05 Linux

Gentoo 以其极致的可定制性著称。本文将基于 systemd 架构和 二进制包（binpkg） 加速方案，带你走完从裸机到完整桌面环境的全过程。

一、 准备工作与磁盘分区

在 Gentoo LiveCD 或其他 Linux 运行环境中开启安装：

1. 初始配置

Bash

passwd                # 设置Live环境密码
rc-service sshd start # 开启远程，方便从另一台电脑操作

2. 磁盘分区

以 /dev/sda 为例，建立 EFI 分区、Swap 和 Root。

Bash

# 格式化
mkfs.vfat -F 32 /dev/sda1
mkswap /dev/sda2 && swapon /dev/sda2
mkfs.ext4 /dev/sda3

# 挂载
mount /dev/sda3 /mnt/gentoo
mkdir -p /mnt/gentoo/efi
mount /dev/sda1 /mnt/gentoo/efi

二、 部署 Stage3 与 Chroot 准备

1. 下载并解压

进入 /mnt/gentoo，下载对应的 Stage3 包并解压：

Bash

tar xpvf stage3-*.tar.xz --xattrs-include='*.*' --numeric-owner -C /mnt/gentoo

2. 挂载必要文件系统

Bash

cp --dereference /etc/resolv.conf /mnt/gentoo/etc/
mount --types proc /proc /mnt/gentoo/proc
mount --rbind /sys /mnt/gentoo/sys && mount --make-rslave /mnt/gentoo/sys
mount --rbind /dev /mnt/gentoo/dev && mount --make-rslave /mnt/gentoo/dev
mount --bind /run /mnt/gentoo/run && mount --make-slave /mnt/gentoo/run

3. 进入 Chroot

Bash

chroot /mnt/gentoo /bin/bash
source /etc/profile
export PS1="(chroot) ${PS1}"

三、 配置 Portage 与系统方案

1. 优化编译参数 (make.conf)

编辑 /etc/portage/make.conf，设置 MAKEOPTS 为 CPU 核心数 +1。

Bash

# 示例：16核处理器
MAKEOPTS="-j17"
# 开启二进制包支持，极大缩短安装时间
FEATURES="${FEATURES} getbinpkg binpkg-request-signature"
# 接受所有自由许可证
ACCEPT_LICENSE="-* @FREE @BINARY-REDISTRIBUTABLE"

2. 配置二进制仓库

编辑 /etc/portage/binrepos.conf/gentoobinhost.conf，使用国内镜像加速：

Ini, TOML

[gentoobinhost]
priority = 9999
sync-uri = https://mirrors.ustc.edu.cn/gentoo/releases/amd64/binpackages/23.0/x86-64

运行 getuto 生成密钥环。

3. 硬件标记与 Profile

Bash

emerge-webrsync
emerge --ask app-portage/cpuid2cpuflags
echo "*/* $(cpuid2cpuflags)" > /etc/portage/package.use/00cpu-flags

# 选择 systemd/plasma 方案
eselect profile list
eselect profile set 28 # 需确认序号对应 systemd/plasma

四、 内核安装：发行版内核方案 (推荐)

对于初学者或追求稳定的人，Distribution Kernels 是最佳选择，它会自动生成 initramfs。

Bash

# 启用发行版内核和固件
emerge --ask sys-kernel/linux-firmware
emerge --ask sys-kernel/gentoo-kernel-bin  # 二进制版最快
# 或者源码版（会自动编译配置）
# emerge --ask sys-kernel/gentoo-kernel

# 确保外部模块随内核自动更新
echo "sys-kernel/gentoo-kernel-bin dist-kernel" >> /etc/portage/package.use/kernel

五、 系统基本设置

1. 区域与时间

Bash

ln -sf ../usr/share/zoneinfo/Asia/Shanghai /etc/localtime
echo "en_US.UTF-8 UTF-8" >> /etc/locale.gen
echo "zh_CN.UTF-8 UTF-8" >> /etc/locale.gen
locale-gen
echo "LANG=en_US.UTF-8" > /etc/locale.conf

2. Fstab 分区表

获取 UUID 并填入 /etc/fstab：

blkid

Plaintext

UUID=xxxx /efi vfat umask=0077 0 2
UUID=xxxx none swap sw 0 0
UUID=xxxx / ext4 defaults,noatime 0 1

3. 网络与 Systemd 初始化

Bash

echo "gentoo" > /etc/hostname
emerge --ask net-misc/dhcpcd
systemctl enable dhcpcd

# systemd 首次启动初始化
systemd-machine-id-setup
systemd-firstboot --prompt
systemctl preset-all

六、 引导程序 (GRUB)

Bash

echo 'GRUB_PLATFORMS="efi-64"' >> /etc/portage/make.conf
emerge --ask sys-boot/grub sys-boot/efibootmgr
grub-install --efi-directory=/efi --removable
grub-mkconfig -o /boot/grub/grub.cfg

七、 桌面环境：Plasma 5/6 与常用软件

1. 安装 KDE Plasma

Bash

# 安装基础显示驱动
emerge --ask x11-base/xorg-server
# 安装桌面套件
emerge --ask kde-plasma/plasma-meta
systemctl enable sddm

2. 音频与字体

Bash

# 启用 Pipewire
systemctl --user enable --now pipewire.service pipewire-pulse.socket wireplumber.service
# 中文字体
emerge --ask wqy-zenhei

3. 常用软件与第三方仓库 (gentoo-zh)

Bash

emerge --ask app-eselect/eselect-repository
eselect repository enable gentoo-zh
emaint sync -r gentoo-zh

# 安装微信/QQ/WPS (处理许可证)
echo "net-im/wechat all-rights-reserved" >> /etc/portage/package.license
emerge --ask net-im/wechat

八、 系统维护技巧

1. 深度更新世界

Bash

emerge -avuDN --with-bdeps=y --binpkg-respect-use=y @world

2. 清理包

Bash

emerge --ask --depclean # 删除无用依赖
eclean-dist             # 清理下载的源码包
eclean-pkg              # 清理二进制包

3. 虚拟机优化 (VMware)

Bash

echo "app-emulation/open-vm-tools gtkmm" >> /etc/portage/package.use/open-vm-tools
emerge --ask app-emulation/open-vm-tools
systemctl enable --now vmtoolsd.service

💡 结语

Gentoo 的初次安装可能需要数小时，但一旦配置完成，你将拥有一个完全契合硬件、极致流畅的操作系统。建议在安装后第一时间建立一次 Stage4 备份，以便在配置出错时快速回滚。
